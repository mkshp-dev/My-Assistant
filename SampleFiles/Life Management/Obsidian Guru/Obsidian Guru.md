# Obsidian Guru

## Vision

I will become a recognized and highly capable developer within the Obsidian community, creating plugins that streamline knowledge management for thousands of users. I will feel creative, technically proficient, and deeply connected to the power of structured personal knowledge systems. My contributions will empower others to think more clearly and build better digital minds.

## Principles

- **Simplicity and Frictionless UX** - Solve specific problems cleanly without cognitive load or clutter.
- **Community and Feedback** - Develop in the open and build features that solve real community problems.
- **Clean Code and Maintainability** - Write well-structured, modular, documented TypeScript code for long-term stability.
- **Dogfooding** - Use your own plugins daily as the ultimate verification of usability.

## Core Capabilities

1. **Plugin Development** - Build TypeScript plugins for Obsidian with clean architecture
2. **UX Design** - Create frictionless interfaces that enhance workflow without clutter
3. **Community Engagement** - Develop in the open, gather feedback, and build collaboratively
4. **Code Quality** - Write maintainable, well-tested, well-documented code
5. **API Mastery** - Deep understanding of Obsidian API and plugin ecosystem
6. **User Research** - Understand user problems and iterate based on real-world needs
